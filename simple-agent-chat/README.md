# Simple Agent Chat

Choose an agent or group in the sidebar to see conversations for those participants. Open an existing conversation or start a new one. In the composer, the highlighted names beside **To** receive your next message. The chat owner sees the entire transcript. Agents receive the messages addressed to them and their own replies.

Use **Manage agents → Settings** for a named Snack agent's written instructions, model and provider account. The composer can set a model for the current conversation. Different named agents can share the same model. External Condiment agents bring their own runtime and personality.

The chat menu can hide or restore conversations. To permanently remove a local transcript and its unshared local attachments, use **Serving Tray → General → Storage → Review conversations**.

Send reports each recipient's status. A message waiting for an external reply can be queued or delivered before the external runtime starts responding. Stop cancels Snack-managed replies. External runtimes manage their own cancellation.

Install this folder through the Condiment Store from GitHub or a local folder. It uses Snack's registered chat actions and live provider catalogue. See [agent workflow documentation](../AGENT-WORKFLOWS.md) and the [external connections guide](../EXTERNAL-CONNECTIONS.md).
