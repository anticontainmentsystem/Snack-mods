Make room for Snack.

A desktop workspace made from small, independent windows called Snacks.

What is Snack?

Snack is a desktop application in private development and internal testing. Create live HTML pages in Main Snack, edit them in Pasta Studio, save independent ChipClips, and launch them from Snack Bars. Arrange Snacks across your monitors, work with images, and manage your workspace through the Serving Tray.

This site hosts the optional Condiment testing catalog and information about the Snack app. A Condiment is an independently installed extension, not the app itself. The desktop app is not currently offered here as a public download.

Connect what you use.

Snack’s Connect tab brings services into the workspace. The built-in Email connector can connect Gmail, Outlook and Zoho through your browser, or a mailbox supporting encrypted IMAP and SMTP. No separate mail client is required. Multiple accounts can coexist.

After connecting, choose the exact email addresses allowed to send commands, choose the areas they can control, and copy the private command setup. Send a structured command to your mailbox; while Snack is running it checks mail, sends a receipt, performs the permitted action, and sends a result email. Each new command requires another explicit email. This is not an unrestricted automatic conversation or a natural-language agent connection.

Google authorization requests read-only Gmail access to find and read command emails, and send access to return receipts/results. Snack does not request permission to delete or modify Gmail messages. Provider consent and public verification requirements still apply; public sign-in rollout is not complete.

Build on top.

Optional Condiments can provide their own interface, agent guidance and integrations. You review their requested controls before enabling them. Agents and extensions use Snack’s discoverable controls, HTTP API and MCP, with the connection’s current permissions.
