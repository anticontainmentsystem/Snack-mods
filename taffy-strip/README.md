# Taffy Strip

Taffy Strip is an optional Windows shortcut launcher for Snack. It has twelve cells and stores up to four shortcuts per cell. Install it through the official Snack Condiments catalog and approve window control and **Save and open local shortcuts selected by you**. It requires a Snack build with the `condiment-shortcuts` capability.

Click a cell to roll out its shortcuts inside the fixed-size strip. Click a card to launch it with Windows. Double-click a cell or use **Manage** to add and arrange shortcuts. **Browse files** accepts apps, files and Windows shortcut files. Use **Browse folders** for directories, **Add link** for an HTTP or HTTPS address, or **Drop files** to open Snack’s native drop zone. Use the arrow buttons to reorder entries and **×** to remove a shortcut from the strip. The orientation button in the Snack bar switches between 12×1.5 landscape and 1.5×12 portrait layouts. In portrait, the controls run along the left edge.

The Condiment uses the shared, local-only `condiment-shortcuts` action. The host resolves approved native targets and retrieves Windows icons. It stores up to 48 entries per installation. The Condiment has no background runtime.
