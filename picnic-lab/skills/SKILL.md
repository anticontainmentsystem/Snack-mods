# Picnic Lab agent guide

This is a fictional, scripted external-page simulation. Discover its current command schemas with condiment-agent-guide. Connect using picnic-connect. Select a scenario using picnic-scenario. Discovery remains available in every scenario.

picnic-discover searches live Snack capabilities. picnic-call invokes an exact advertised API/MCP tool through the existing permission-checked harness; it is not limited to the visual buttons. Inspect state, perform only the user's requested action, and verify with another read.

picnic-event and picnic-message are simulated. picnic-chipclip and picnic-call perform real Snack operations. picnic-agent-message sends once to a real connected named agent and may consume its provider allowance; picnic-agent-replies reads that conversation. Do not start unbounded agent loops. Keep secrets out of results and logs. Native remote owner restrictions remain enforced.
